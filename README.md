# Solo Assecuratio – aktualizacje

Tu leżą instalatory programu **Solo Assecuratio** (folder `instalatory`) oraz plik
`latest.json`, z którego program sprawdza, czy jest nowa wersja.

To repozytorium nie zawiera kodu programu ani żadnych danych klientów.

## Najnowsza wersja: 0.4.1

[Pobierz instalator 0.4.1](instalatory/SoloAssecuratio_0.4.1_setup.exe)

Lepszy czytnik dokumentów, zwroty Pani/Pan w mailach, rozpoznawanie osoby i firmy,
powiększanie podglądu dokumentu, wysuwany notatnik, oznaczone pola wymagane.

Zainstalowany program sam pokaże pasek z aktualizacją – nie trzeba pobierać ręcznie.
